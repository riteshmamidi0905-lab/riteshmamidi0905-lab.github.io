    How to use this demo

    This is a working application on synthetic data. Orders, stock, money, tickets, approvals and the audit log all come from one in-browser state engine, so a change in one module shows up in the others.

    1. Open Guided walkthrough (about 75 seconds): it performs real actions step by step and explains each in plain language. Engineers can open the Technical view.
    2. Or go to Sales, submit an order, then watch Inventory, Finance and the Governance audit log.
    3. Switch the Demo role to see actions refused and recorded.
    4. Reset demo restores the deterministic starting state.

    State is kept in your browser's local storage as a demo convenience. It is not a database, is not sent anywhere, and no visitor data is collected. The AI agents are rule-based demonstrations; no language model runs here. The platform has not been validated for production.
