    Architecture

    Business problem

    A simulated hospitality team needs current cold-storage guidance, without mixing tenants or silently replacing a reviewed policy.

    Customer requirements

    • Ingest bounded Markdown and preserve document history.
    • Retrieve only the requesting tenant’s active content plus shared synthetic policies.
    • Cite the exact document version and abstain when evidence is missing.
    • Reject known instruction attacks without replacing the active version.

    Architecture decision

    Use source extraction and deterministic hashing vectors for a reproducible baseline. Versioned provenance matters more here than fluent generated prose.

    Implementation

    A strict document schema validates identifiers and content. One transaction activates a content-hashed version; a partial unique index enforces a single active version per tenant/document. The retriever blends cosine similarity with lexical coverage and copies a cited chunk. Historical versions can be deliberately reactivated.

    Security

    Tenant identity is server-derived. Document text is treated as data and cannot invoke tools or fetch URLs. Known injection forms are screened; this regex screen is not a complete prompt-injection defense.

    Evaluation methodology

    Eight deterministic development fixtures check answer status, citation and required evidence. Added control tests exercise document ingestion, tenant isolation, active-version replacement, replay, rejected updates and persistence. The fixtures are same-author development data, not held-out model evaluation.

    Measured local results

    • Cold-storage answer cites the full ingested version hash and the 4°C source text.
    • Known injected replacement returns 422; the previous active policy remains.
    • A second tenant abstains on the private fixture.
    • Original retrieval suite: 8/8; screening-disabled control: 6/8.

    Limitations

    No learned semantic embeddings, ANN index, live LLM, large held-out corpus or guarantee that an uploaded source is factually correct.

    Business value

    Makes policy provenance and stale-document handling inspectable. A real pilot should measure correct-policy resolution time and escalation rate; no customer savings or ROI was measured.
