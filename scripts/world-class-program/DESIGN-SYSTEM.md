# Proposed NASHA visual direction — owner acceptance required

This is a creative specification and storyboard direction, not a completed premium environment or visual PASS. Research observations and limitations are catalogued separately; no other site's proprietary design, media or code is copied.

## Identity, typography and color

Lead with **Ritesh Mamidi — Applied AI & Product Analytics**. Secondary: Forward Deployed Engineering, AI Systems, Enterprise Automation and Data Engineering. Founder/business and independent engineering evidence are distinct; professional client engagement remains accurately designated and never presented as direct Apple employment. Four approved PDFs remain unchanged.

Use existing licensed Inter for clear body/navigation and JetBrains Mono for event IDs, quantities and code; do not add a display-font download merely to appear premium. Large editorial headings, short prose, a small number of useful controls and generous spacing establish hierarchy. Body text starts at 16 px; labels never substitute for accessible names.

Proposed interface tokens: limestone `#E8E2D6`, ink `#111A1D`, muted text `#B9C7C6`, steel `#364247`, evidence cyan `#95E4D1`, restrained marigold `#D98C32`. Validate final contrast on actual surfaces. Status uses text/icons in addition to color. Approved character colors and pixels stay unchanged.

The brewery inherits the original limestone, board-formed concrete, blackened steel, stainless tanks, copper kettles and pecan/cedar-elm palette. Bone terrazzo and controlled marigold detail replace generic gold/neon ornament. HQ is a related but separately proposed research-campus expression, not a clone of a technology brand or an operating campus.

## Architecture, camera and light

One plan must explain entrance, circulation, atrium, VECTRA workstation, receiving boundary and brewery/court sightlines. Match structural scale and material junctions across shots. The original six-tank horseshoe is a concept visual motif, not a real capacity specification. Do not import the rejected eight-tank night composition as geometry authority.

Camera intent: stable human-height arrival, wide architectural establishment, medium workstation context, close readable instrument view, then a controlled return to the room. Focal lengths and eye heights are starting authoring parameters requiring actual composition review, not delivered photographic specifications. No forced first-person walking, scroll hijack or automatic tour camera. Visitors choose the next frame; motion is opt-in, pauseable and fully replaceable by stills/text.

HQ daylight should reveal depth, scale, glass thickness, real surface detail and shadows. Brewery evening light remains warm without an orange wash or emissive bloom hiding geometry. Bake indirect light where appropriate; one restrained live shadow source and adaptive quality precede expensive post-processing. Fake procedural material names do not establish textured limestone or timber.

## Character and dashboard presentation

Use the twelve existing identities and verified responsibilities. Show task, tool, inputs/outputs, decision and evidence together, with clear Recorded / Deterministic Simulation / Implemented / Conceptual / Not Implemented labels. Display the current event's specialist; never force an unrelated agent into a mission. Retain static art and animation-pending labels until source assets pass the gate.

Separate task/status context from detailed JSON so recruiters can understand the purpose before opening contracts. Do not display generated-looking pseudo-reasoning. Financial cards must drill into actual synthetic rows. Initial discovery must not download all recordings or a 3D scene; after engagement, do not sacrifice verification for responsiveness.

## Mobile and access

Keep a complete semantic 2D experience, no mandatory audio/avatar, readable type, at least 44 px controls, visible focus, keyboard navigation, status announcements and pause/replay. Honor reduced motion from the start and allow an explicit opt-out. On small devices use static architectural compositions or low-power opt-in 3D rather than forced full-scene rendering. Context restoration must preserve selected event, role and ledger; image/animation state never authorizes work.

Approval of this direction is required before expensive asset production. It does not authorize spending, approve a new likeness, certify character fidelity or permit release.
