## Founder-guide production plan

Use the existing silent approved guide as an optional controlled introduction/navigation aid. Its off state must preserve all recruiter, project, experience, resume and contact navigation. Display pause/disable and respect reduced motion from startup, showing the still version when appropriate. Do not obscure controls, trap focus or autoplay audio.

Separate three possible modes clearly: (1) existing/prerecorded cinematic imagery, (2) scripted navigation tied to explicit visitor actions, (3) actual conversational AI, which is not implemented by an animated portrait and would require a separately scoped, evaluated and authorized integration. No live-inference or new credential work is started here.

Future context scripts may introduce HQ, proposed brewery, synthetic enterprise and real engineering evidence. They must state simulated/recorded/proposed boundaries, keep independent projects separate from employment and accurately describe Apple Maps Client Engagement. A new likeness or voice request requires explicit owner approval before production, not inferred approval from this program.
