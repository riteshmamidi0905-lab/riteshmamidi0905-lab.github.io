RAG combines retrieval with a reader that can point to source passages. The preserved GenAI Document Assistant uses an extractive default and abstention when evidence is insufficient.

Scores + hard gates

Evaluate

Weighted quality scores and hard grounding thresholds answer different questions. The LLM Evaluation Framework keeps them separate so a good average cannot hide a failed gate.

THE WEIR + approval

Govern

THE WEIR is a separate MCP security gateway. Policy, argument binding and single-use approvals are distinct controls. This static portfolio has no authority to perform protected operations.

Trace + failure analysis

Observe

A useful trace records tool requests, decisions, outcomes and failure causes. NASHA’s pinned offline integration includes recorded handoffs and audit events, not a live operational feed.

Implementation scope. The project repositories contain implemented components. This website presents architecture, recorded evidence and browser demonstrations. It does not connect those components into a deployed enterprise platform.
